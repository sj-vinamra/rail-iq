Verification

Method & assumptions

Use on P2427. Appendix 5 §2.11.1 and Annex 2 §3.3.8 / §4.8 name the Isograph tools (FaultTree+, AVSim, Reliability Workbench) for the contract analyses. Rail-IQ is a design-stage tool: build and test the logic quickly here, then reproduce the model in Isograph for the deliverable and compare the two results. The Excel export uses one row per gate, event or block to make that re-entry straightforward. Sample failure data is illustrative, not project data.

Fault tree

  • Gates: OR, AND and VOTE (k of n inputs failed). Coherent logic; NOT gates are not supported.
  • Events: repairable q = λτ/(1+λτ), w = λ(1−q); proof-tested q = 1 − (1 − e^(−λT))/(λT) + λτ ≈ λT/2 + λτ, w = λ(1−q); non-repairable q = 1 − e^(−λt) at the mission time; probability q = p; initiating event w = f, q = 0.
  • Top event Q and W are solved exactly with a binary decision diagram: P = q·P(hi) + (1−q)·P(lo), W = w·(P(hi) − P(lo)) + q·W(hi) + (1−q)·W(lo), which equals Σ wᵢ·∂Q/∂qᵢ. The rare-event and min-cut upper-bound values are shown for comparison with tools that use them.
  • Minimal cut sets come from Boolean expansion with absorption; repeated events are handled exactly. Cut-set frequency W = Σᵢ wᵢ Π_{j≠i} qⱼ.
  • Common cause: β-factor. Members keep (1−β)λ; a common event with βλ (mean of the members) is OR-ed into each member.
  • SIL band of W from EN 50126-2:2017 §10.2.7 Table 2. The target THR comes from the SIL determination; the samples assume SIL 2.
  • Importance: Birnbaum ∂Q/∂qᵢ; criticality Iᴮ·qᵢ/Q; Fussell-Vesely on Q and on W from the cut sets; RAW Q(qᵢ=1)/Q; RRW Q/Q(qᵢ=0).

Reliability block diagram

  • Blocks: n identical units with k required, MTBF (exponential) or Weibull (β, η, mean life η·Γ(1+1/β)), MDT = MALDT + MTTR (Annex 2 §4.10.9), optional proof test with MUFT = T/2 added to the down time (Annex 2 §3.3.1).
  • Groups: series, parallel, k of n, standby. The diagram is turned into failure logic and solved with the same BDD. Availability A = 1 − Q, MTBSAF = MUT = A/W, MDT = Q/W, which matches Annex 2 A = MUT/(MUT + MDT).
  • Steady-state availability uses the mean life of each block, which holds for any failure distribution with renewal at repair. Reliability without repair uses the full Weibull or exponential curve.
  • Single points of failure are the order-1 minimal cut sets of the SAF model (Annex 2 §4.8). Blocks marked non-SAF are left out of the SAF model and counted only in the all-failures MTBF.
  • Subsystems are the top-level groups. Their predicted λ(SAF) is compared with the λ(SAF) budget entered on the group.
  • The analytic model treats standby as active redundancy with independent repair (one repair team per unit). Use the Monte Carlo simulation for cold standby, switching failure and non-exponential repair.

Not covered

Event trees, Markov models with shared repair crews, phased missions, spares and logistic simulation, NOT logic, uncertainty analysis, and failure-data libraries (NPRD, FMD, EN 61709). These are reasons to keep Isograph for the contract deliverables.
